# Остров

Dynamic Island для телефонов Google Pixel: живая пилюля вокруг фронтальной камеры в стиле Material 3 Expressive.
Работает без root — через службу специальных возможностей и доступ к уведомлениям.

## Что умеет
- Музыка, звонки, навигация, таймеры, зарядка, Live Updates и десятки системных событий
- Полная настройка вида: размеры, формы, цвета, анимации, раскрытый вид
- Жесты, сценарии «если — то», профили, полка, виджет, плитка быстрых настроек
- Русский и английский интерфейс

## Сборка
Нужны JDK 17+ и Android SDK (compileSdk 37).

```
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/`.

Минимальная версия Android — 12 (API 31).
